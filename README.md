# ChatNote

在 ChatGPT 旁边摘录、编辑与保存 Markdown 笔记的浏览器扩展。

## 安装

Chrome / Edge 打开扩展管理页，开启开发者模式，选择“加载已解压的扩展程序”，选择含 manifest.json 的本目录。刷新 ChatGPT 页面后使用。

## 功能

- 每个具体聊天独立关联笔记；首页隐藏文档及入口。
- 左右分栏，拖动文档左边界同步调整宽度。
- 选中聊天正文（支持多段落、跨消息）或悬浮表格，可加入文档；保留文字格式与表格，插入到文档原光标位置。
- Markdown 标题、无序列表与待办；Ctrl+P 提供六级标题、检查列表、引用、高亮块及3×3表格。
- 表格右边缘与横线交点插入行、底边缘与竖线交点插入列；左侧、顶部选中整行列后删除，支持撤销。
- 笔记自动保存到浏览器扩展本地存储；“选择保存位置”将当前内容写入MD文件。位置详情在文件名下方展开查看。
- 最近两条用户消息的本地规则命名，不使用ChatGPT聊天标题；手动名称优先。

## 保存说明

浏览器自动保存与MD文件保存相互独立。扩展不会自动将每次编辑同步到MD文件，需点击“选择保存位置”写入。卸载扩展可能清除本地笔记。文件夹由用户授权，浏览器不提供完整系统路径，也不直接打开系统文件管理器。

## 源码

| 文件 | 职责 |
|---|---|
| manifest.json | 扩展声明 |
| content.js | 分栏、编辑器、摘录、表格、菜单与原生文件保存 |
| naming.js | 无网络请求的主题命名模块 |
| background.js | 本地存储、版本冲突与文件保存元数据 |
| tests/ | 命名专项和模拟集成检查 |

## 开发检查

需要Node.js 20或以上：

```sh
npm install
npm run check
npm test
```

测试模拟DOM和文件系统API。真实ChatGPT页面、原生文件夹权限、中文输入法及分栏视觉效果仍需Chrome/Edge实机验收。

### 浏览器摘录回归

运行 `npm install`、`npx playwright install chromium`，再运行 `npm run test:browser`。也可用环境变量 `CHROME_PATH` 指定本机 Chromium。测试使用本地模拟聊天页面和存储接口，执行真实浏览器鼠标拖选与按钮点击，不访问用户对话。

更新扩展时，将新版文件覆盖原先加载的扩展文件夹，在 `chrome://extensions` 点击 ChatNote 的重新加载按钮，并刷新已打开的 ChatGPT 页面。请勿同时启用两个 ChatNote 版本。

0.22.4：兼容不提供 `data-message-author-role`、`main article` 或 conversation-turn 标记的聊天页面。此时从用户主动选中的内容提取摘录，排除导航、输入框和按钮。
